Componentes-exemplo para o Codex integrar ao projeto **após inspecionar a arquitetura real**. Não importam composições anteriores nem criam vídeos sozinhos. Para `FocusZoom`, renderize o trecho dentro de uma `<Sequence>` e garanta que as coordenadas do `target` são as do canvas **após** recorte em 9:16; caso venham do arquivo original, converta conforme objectFit/crop. Para detalhe que se move, adapte para keyframes ou tracking validado; nunca deixe o marcador fixo em coordenadas erradas. Use `Img` para asset local já resolvido com `staticFile()` no lugar de caminho arbitrário.

Vídeo temporalmente correto precisa de seleção de clipe e montagem pela estrutura atual do projeto. Estes componentes cuidam apenas de apresentação. `FreezeReplay` (replay ou alteração de velocidade do clipe) deve ser adaptado pelo Codex ao componente de vídeo atual, respeitando offset, áudio e frames.
