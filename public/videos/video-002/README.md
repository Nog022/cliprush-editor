# Video 002 — recursos

Esta produção é desenhada por código em Canvas e React. Não depende de imagens, fontes, vídeos ou APIs externas. Os personagens, ambientes, partículas e geometria são originais desta produção.

A primeira versão é silenciosa. Nenhuma narração, música ou efeito sonoro foi incluído.

Para áudio futuro, guardar aqui somente arquivos locais com licença adequada, registrar sua origem e preencher `audioCues` da composição. Os pontos de sincronização estão em `src/videos/video-002/constants.ts` e no arquivo `audio-cues.json`, que é uma lista de eventos, não uma lista de mídias existentes.
