# Skills do ClipRush

As 12 Agent Skills oficiais instaladas estão em `../.agents/skills/`, na versão 4.0.539, com origem `remotion-dev/skills` registrada em `../skills-lock.json`. Esta pasta reúne procedimentos do projeto sem duplicar ou alterar as skills oficiais.

| Skill | Quando consultar |
| --- | --- |
| `remotion-best-practices` | Ponto de entrada e seleção das demais skills |
| `remotion-create` | Criar uma produção ou composição |
| `remotion-markup` | Componentes, animações, assets e efeitos |
| `remotion-interactivity` | Timeline e propriedades editáveis no Studio |
| `remotion-captions` | Transcrição e legendas |
| `remotion-multimedia` | Operações de mídia com Mediabunny |
| `remotion-maps` | Mapas e rotas |
| `remotion-studio` | Preview e opções do Studio |
| `remotion-render` | Exportação de vídeos e frames |
| `remotion-docs` | Consulta à documentação atual |
| `remotion-saas` | Aplicações com Player ou serviços de render |
| `remotion-upgrade` | Atualizações explicitamente planejadas |

Abrir o `SKILL.md` da skill escolhida dentro de `.agents/skills/<nome>/` e seguir as referências relevantes. Procedimento local: [produção](producao.md). Regras gerais: [AGENTS.md](../AGENTS.md).
